# User Feedback - 8 January 2025

Testing done on Quiz Your Club (West Ham)

---

## Bugs to Fix

### 1. Timer Expiry Shows "Correct" (CRITICAL)
When the timer runs out, the question auto-marks as "correct" - this is wrong. Should mark as incorrect/unanswered.

### 2. Survival Mode Unlock Logic (CRITICAL)
Currently requires 5 quizzes to unlock Survival Mode, but only West Ham is free. This forces users to play the same club quiz 5 times before unlocking anything else. This is a poor user experience - rethink the unlock requirements.

---

## UI/UX Improvements

### 3. Answer Box Backgrounds Too Faint
The question answer boxes have backgrounds that are hard to see. Need better contrast/visibility.

### 4. Timer Needs Warning States
When time is running low, there's no visual/audio warning. Easy to miss "Time's Up". Add:
- Colour change when time is low (e.g., turn red under 5 seconds)
- Maybe pulse/shake animation
- Optional sound warning

### 5. Level/Amateur Badge on Home Screen
The "Level 1 Amateur" display at the top may not be well explained and clutters the main page. Consider:
- Moving it elsewhere
- Making it less prominent
- Adding explanation/onboarding

### 6. Lock Icons Could Be Better
The lock icons on locked modes are functional but could be more polished. Consider subtle animation or better styling.

---

## What's Working Well

- Haptic feedback feels good
- Premium star badge and yellow shimmer button look great
- Premier League Legends mode is a strong feature (consider promoting it higher?)
- Overall question quality is good
- Time limit mechanic is engaging (when it works correctly)

## Design Decision: Move Stats Off Home Screen

**Problem:** The gamification header (Level 1 Amateur, streak, XP) takes up screen real estate, pushing Premier League Legends (a strong mode) below the fold.

**Proposed solution:** Move full stats display to a separate Stats page.

**Home screen would show:**
- Game modes list (Premier League Legends visible without scrolling)
- Small stats icon/button in app bar to access Stats page
- Optional: Minimal streak indicator (just flame + number) if we want some visibility

**Stats page would contain:**
- Full level display with title
- XP progress bar
- Streak counter
- Achievements
- Other progression metrics

**Benefits:**
- Strongest content visible immediately
- Cleaner, more focused home screen
- Less overwhelming for new users
- Stats become a destination for engaged users
- Similar pattern to Duolingo

---

## Visual Polish: Home Screen Feels Bland

**Problem:** Too much blue monotone, grey text hard to read, locked modes look dead/boring with grey icons. Overall feels flat and lacks energy despite being "professional".

**Goal:** Keep the Sky Sports professional vibe but make it more exciting.

**Ideas:**

1. **Coloured icons always** - Even locked modes show their accent colour (just dimmed or with lock overlay). Grey = broken, not "locked".

2. **Better text contrast** - Secondary text is too faint. Needs to be more readable.

3. **Accent colours / subtle gradients** - Break up the blue monotone. Sky Sports uses bold colours against dark backgrounds.

4. **Entry animations** - Game mode cards fly/fade in one-by-one on first load. Staggered animation feels premium.

5. **Micro-interactions** - Subtle idle animations, gentle pulse on modes close to unlocking.

6. **Lock icon styling** - Current locks are boring. Could animate, add shimmer, or make them feel like "unlock me" rather than "not available".
